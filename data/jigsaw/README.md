# Jigsaw Dataset

Place Kaggle Jigsaw Toxic Comment files here locally:

```text
data/jigsaw/train.csv
data/jigsaw/test.csv
data/jigsaw/test_labels.csv
data/jigsaw/sample_submission.csv
```

These raw files are intentionally ignored by Git. The six thesis labels are:

```text
toxic, severe_toxic, obscene, threat, insult, identity_hate
```
